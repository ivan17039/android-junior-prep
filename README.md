# JobPrepApp

Vježba Android aplikacije napravljena kao priprema za poziciju Junior Android Developera.

## Što aplikacija radi
Prikazuje listu knjiga i omogućuje pregled detalja svake knjige.

## Ekrani
- **Book List** – scrollable lista svih knjiga
- **Book Detail** – detalji odabrane knjige (naslov, autor, godina)
- **About** – kratki opis aplikacije

## Tehnologije
- Kotlin
- Jetpack Compose
- Navigation Compose
- Material 3

## Kako pokrenuti
1. Kloniraj repozitorij
2. Otvori u Android Studiju
3. Pokreni na emulatoru ili fizičkom uređaju (Run ▶)
